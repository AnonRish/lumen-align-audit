# Code of Conduct

This project aims to be a welcoming, harassment-free space for everyone,
regardless of experience level, background, or identity.

## Expected behavior
Be respectful and constructive in issues, PRs, and discussions. Assume good
faith. Focus criticism on the work, not the person.

## Unacceptable behavior
Harassment, personal attacks, discriminatory language, and deliberately
disruptive behavior will not be tolerated.

## Enforcement
Report violations by opening an issue or contacting the maintainer directly.
