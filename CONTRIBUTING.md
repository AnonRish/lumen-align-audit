# Contributing to Lumen

Lumen is built around a specific honesty policy: STATUS.md tracks exactly
what's real, tested, and verified versus what's a documented scaffold.
Contributions are welcome, held to that same standard.

## Before opening a PR
- Run the test suite (pytest tests/) and make sure it passes.
- If you're adding a new experimental result, include the actual numbers
  from running it, not an estimate.
- If something is a scaffold or untested, say so in the docstring, the same
  way the rest of the codebase does.

## Good places to start
See STATUS.md's known-limitation notes, and issues tagged 'good first issue'.
